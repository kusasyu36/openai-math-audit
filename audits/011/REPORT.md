## 1. 主張の正確な内容

**Thm 1.1**（01-introduction.tex）
- 素数 p について、p−1 の素因数を大きい順に並べ、それぞれの対数を log(p−1) で割った列を (V_1(p), V_2(p), …) とする。
- この列の有限次元分布が、素数を均等に数えたとき PD(1) に収束する、という主張。
- これで Ford–Konyagin–Luca の予想と、Granville の予想 #{p≤x : P⁺(p−1) ≤ x^{1/u}} ~ ρ(u)π(x)（u 固定）が解決されたとしている。
- 例: P⁺(p−1) > x^0.9 を満たす素数の割合は log(10/9) ≈ 0.105（スクリプトで計算）。

**Thm 3.1**（03-determinant.tex:37–61）
- パラメータ: L = log x、W = exp(L^0.24)。
- 帯（bands）: P_i = [exp(L^{a_i}), exp(2L^{a_i})]、0.1 < a_1 < … < a_K < 0.2。
- 重み: 𝒲(h) = q^{ω(h)−K} Π_i ω_i(h)/V_i。
- 係数の条件:
  - α_m = m^{iv}(1_{m 素数} − 1_{m rough}/(V(W) log m))
  - β は任意で、W-rough な数に台を持ち、|β| ≤ L^C
  - H_m, H_n ≥ x^δ
  - F は |F| ≤ 1 で、帯の素数 p について F(ph) = F(h) を満たす任意の関数
- 結論: |Σ α_m β_n F(mn−1) 𝒲(mn−1)| ≪ X L^{−D*}。D* は任意で、K を十分大きく取る。

**証明の骨格**
1. h（帯の素数を除いた部分）について Cauchy–Schwarz を使い、F を完全に消す。
2. 残る二乗 Q_Y（l.105）は、帯の素数の積 a, b ~ Y = exp(L^{0.1〜0.2}) による乗法的なずらしの相関になる。
3. lift P = (Dbm, s)、Q = (Dar, n) を取ると det(P,Q)/D = bmn − ars になる。これで、行列式の条件に対する作用素の pairing に書き直す。
4. 小弧部分（minor arcs）: (AA*)^R の trace を root 平均し、独立な射影直線のモデルに置き換え、signed memory 展開で処理する（Prop 4.1）。**この部分は係数に依存しない。**
5. 大弧部分（major arcs）: Prop 5.1。α について使うのは Lemma 5.2（指標 χ mod ≤ L^{A0}、|t| ≤ 2XL^B での Mellin 相殺。Vinogradov–Korobov 型）だけである。

## 2. 既知の限界との比較（最重要）

### (a) F が任意であることから、絶対値付きの EH 型推定が出る

- F(h) = Σ_{ℓ∈(x^0.9, x^{1−ε}) 素数, ℓ|h} c_ℓ（|c_ℓ| ≤ 1）とおく。
  - h ≤ 2x なので、x^0.9 を超える素因数は高々 1 個。よって |F| ≤ 1。
  - ℓ は帯の素数ではないので、F は帯の素数について不変。
- c_ℓ を符号に取ると、Thm 3.1 から次が出る:
  **Σ_ℓ |Σ_{mn≡1 (ℓ)} α_m β_n 𝒲(mn−1)| ≪ X L^{−D}**
- これは「印付き、水準 0.9〜1−ε、素数の法、剰余類固定、法について絶対値付き」の Elliott–Halberstam 型の分布である。対象は Type II 畳み込み（素数 − proxy）*（任意の β）。
- 既知の結果:
  - Bombieri–Vinogradov: 水準 1/2。
  - BFI / Fouvry: 1/2 を超えるのは well-factorable な重みが必要で、絶対値は付けられない。
  - Zhang / Polymath: 滑らかな法で 1/2 + 7/300。
  - Maynard: 3/5 程度。
  - 素数の法・任意の β で水準 1 に近いものは前例がない。
- 029 が実際に使う F = 1{h/h_P = cQ, Q > x^0.9 素数}（029 12-construction.tex:46）も、まさにこの水準 0.9 の内容である。
- Baker–Harman の記録 P⁺(p−1) ≥ p^0.677 は、正の割合の下界にすぎない（監査役の知識の範囲で、その後の改善があっても小幅のはず）。Thm 1.1 はこれを 1−ε まで漸近式として超える。

### (b) parity barrier との関係

- 篩だけの議論が parity を破れないのは周知である。本論文の parity 破りは Type II（Thm 3.1）が担っており、構成として筋は通っている。
- 流れ: 合成数 v = p_1⋯p_j の素数を rough な proxy に置き換える。すると rough の世界の話は Titchmarsh 約数問題型になり、BV で届く。
- したがって「parity barrier に正面から反する」とは言えない。**問題は Thm 3.1 の強さそのもの**である。

### (c) 係数への依存の抽出から、Chowla 型の帰結が出る

- 029 Lemma 10.2 と監査役の読み（§3–5）のとおり、証明が α について使うのは次の 2 点だけである:
  - 大きさの上界と rough な台
  - (10.6)、すなわち Lemma 5.2 型の Mellin 相殺
- α_m = λ(m)1_{rough}（Liouville 関数）は VK 零点のない領域と Siegel の定理から (10.6) を満たす。
- そこで β_n = λ(n)1_{rough}、F(h) = λ(h/h_P) を取ると、
  **Σ_N λ(N)λ(N−1) r(N) λ((N−1)_P) 𝒲(N−1) ≪ X L^{−D}**（D は任意）
  - r(N) は N = mn（m, n は rough で、所定の範囲）と分解する方法の数
  - 主項の大きさは X L^{−0.48} なので、自明でない主張である
- これは「印付き・自然密度・任意の対数冪の節約」を持つ 2 点 Chowla 型の推定である。既知の結果と比べると:
  - Tao: 対数平均で、速度なし。
  - Helfgott–Radziwiłł: (log log)^{−1/2}。
  - Pilatte: 対数平均で対数冪の節約。
  - Tao–Teräväinen: 自然密度だが「ほとんどすべてのスケール」でのみ。
- 同様に F = 029 の F を使えば、ずらした素数上の Liouville 関数（λ(kQ+1)、k ≤ x^0.1 で平均）という parity が難しい型の主張も出る。
- **反例ではない**。ただ、証明が正しければ有名な未解決問題を同時に大きく進めることになり、強い警戒信号である。
