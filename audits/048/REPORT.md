## 1. 主定理と証明の流れ

**定理 1.1**: 次を満たす A と m が存在する。
- A は有限生成・正規・整域の ℂ 代数で、Krull 次元は 2。
- m は A の極大イデアル。
- Der_ℂ(A) ≅ A²（微分加群が階数 2 の自由加群）。
- A_m は正則でない。

**証明の流れ**:
1. §2: P¹×P¹ 上で曲線 C を作る。双次数 (8,4)、種数 21、楕円曲線 Γ と Z で 4 次の接触をもち、L = H+Z（次数 10）について 4L ≅ K_C。
2. §3: トレース形式（分裂型 (3,0,0,−3)）から、有理型のペア P と留数恒等式を得る。
3. §4: ジェットの帰納法。2 次の障害は、対称部分を留数定理で、反対称部分を Σ(W_j−1) = −9 deg L で消す（核心）。
4. §5: Grauert の縮約、形式関数定理、Hartogs 拡張で T_X ≅ O_X² を得る。K_Y·C = 50 > 0 なので特異。
5. §6: Artin 近似と、自前で証明した有限決定性補題で代数化する。
