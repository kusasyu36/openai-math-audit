## 1. 主定理

**定理 1.1**: 任意の r, m ≥ 1、R ≥ 2、D ≥ 1、彩色 χ: ℕ → [r] に対して、正の整数 a₁ < … < a_m と色 c が存在して、次が成り立つ。
- 空でない任意の J ⊆ [m] について χ(Σ_J a_j) = χ(Π_J a_j) = c。
- 分離条件 (1.1) を満たす。

**系 1.2**: |FS(A)| = |FP(A)| = 2^m − 1、かつ FS(A) ∩ FP(A) = A。
