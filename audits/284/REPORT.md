  - α_tot = 4 の意味は「4 未満のすべての指数を否定する」であって、R ≥ Q^4/polylog を満たす関数を一つ作ったわけではない。そのため、成果一覧の見出しの「optimal quartic separation」は少し言い過ぎで、論文のタイトルの "Nearly Quartic" のほうが正確。
- ABKRT21 の予想 R = O(Q^3) を否定するのは **k ≥ 3** の場合だけ（k = 2 では指数がちょうど 3）。論文の要旨にはこの条件が明記されていない。

## 1. 主定理

対象は全域ブール関数 F_{k,m}。R は有界誤差の乱択クエリ計算量、Q は有界誤差の量子クエリ計算量で、どちらも最悪ケースで数える。

定理 1.1: k ≥ 2 を固定し、m を十分大きい 4 のべきとする。
- Q ≤ C_k √m (log m)^{b_k}
- R ≥ c_k m^{2−1/k}/(log m)²
- したがって R ≳ Q^{4−2/k}。指数は k = 2〜7 で 3, 10/3, 7/2, 18/5, 11/3, 26/7（有理数で厳密に計算して確認した）。

**文献との関係**:
- ABKRT21 は上界 D = O(Q^4) と、予想 R = O(Q^3) の出典。
- 三乗の分離は BS21 の Cor. 1.5、および Sherstov–Storozhenko–Wu による。
- 引用されている BK26（arXiv:2609.15063）と AIK26（arXiv:2609.11664）は実在した。どちらも C 対 R/Q の分離の論文で、本論文の新規性の主張とは矛盾しない。

## 4. 懸念点

- **明確な誤り**: なし。
- **ギャップ**: 重大なものはなし。軽微な点として、補題 2.1(1) は BS21 の明示されない定数（k^{-29}、「N が十分大きい」）に頼っている。k を固定すれば漸近的には問題ない。
- **説明の分かりにくさ**
  1. 「三乗予想を否定」には k ≥ 3 が必要だが、明記されていない。
  2. 量子上界の log の指数は、実際には k に依存しない。
  3. 補題 3.1 の平均下界が緩い（正しさには影響しない）。
  4. 「4 乗を達成」と読める表現がある。
  5. 入力長 ~m^{22} が明記されていない。
