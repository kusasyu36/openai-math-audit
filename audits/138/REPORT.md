## 1. 主張の正確な内容

**Thm 1.1（introduction.tex:58–72）**
- 入力: 正整数 a_1..a_n（重複可）と目標 t ≥ 0。n ≥ 2。b = 入力整数と t の最大ビット長。
- モデル: word RAM、語長 w = ⌈4(n + b + log₂(n+2))⌉（introduction.tex:39）。単位費用演算は読み書き・間接参照・比較・加減乗除（剰余）・ビット演算・シフト。一様乱数 w ビット語の取得も 1 演算。乱数は一方向（保存しない限り再利用不可）。乱択オラクルや外部表はなし。
- 一様性: n, b に依存しない単一の有限プログラム。前処理・表の構成もすべて時間に含む。
- 結論: 停止は毎回。正答確率 ≥ 2/3（入力ごと、内部乱数について。両側誤り）。各固定 c について定数 C_c, N_c があり、n ≥ N_c, b ≤ n^c なら**すべての乱数結果で** C_c 2^{0.49n} 演算以内。
- 中間的な上界は 2^{0.489995n} poly(n+b+2)（introduction.tex:78–80）。0.49 との差 0.000005 で多項式因子を吸収する（implementation.tex:332–343）。
- 判定問題のみ。証拠（部分集合）の出力は主張していない。空間も 2^{0.49n} 語程度（低空間は主張していない）。

## 2. 既知の結果との比較

| 結果 | 時間 | 空間 | 備考 |
|---|---|---|---|
| Horowitz–Sahni 1974 | 2^{n/2} | 2^{n/2} | 決定的 |
| Schroeppel–Shamir 1981 | 2^{n/2} | 2^{n/4} | 決定的 |
| Nederlof–Węgrzycki 2021 | 2^{n/2} poly | 2^{0.249999n} | **空間**の改善（時間の対数因子改善ではない） |
| Chen–Jin–Randolph–Servedio 2023 | 2^{n/2} n^{−γ}, γ > 0.5023 | — | 時間の多項式因子改善。word/circuit RAM、語長多項式 |
| 本論文 | 2^{0.49n} | 2^{0.49n} | 指数の改善。乱択、両側誤り |

- 依頼文の「Nederlof–Węgrzycki 2021 の 2^{0.5n} の対数因子改善」は不正確。NW2021 は空間の改善で、時間の多項式因子改善は CJRS2023（arXiv:2301.07134）である。論文の introduction.tex:19–24 は正しく引用している。
- 平均ケース: Howgrave-Graham–Joux 2010 (2^{0.337n})、Becker–Coron–Joux 2011 (2^{0.291n}) はランダム入力のみ。本論文は最悪ケースを主張する。
- Austrin–Kaski–Koivisto–Nederlof 2016（arXiv:1508.06019）: 最大ビン（同じ和をもつ部分集合の最大数）が 2^{(0.5−ε)n} 以下、または 2^{0.661n} 以上なら 2^{n/2} を真に破れる。残る困難ケースは密度 ≈ 1。本論文の「欠損度 d(V) の二分法」（setup.tex:66–74, 211–222）は同系の発想で、密度 1 付近を alias 抽出＋チェックサムで処理する点が新しい。
- 下界・仮説との整合: Subset Sum の指数 1/2 に結びつく既知の仮説（SETH 等）はない。ABHS 系の SETH 下界は擬多項式 t^{1−ε}2^{o(n)} に関するもので、2^{n/2} とは無関係。**本主張は既知の下界・困難性仮説と矛盾しない**。ただし「2^{n/2} 障壁を最悪ケースで破る」は長年の未解決問題（AKKN2016 が明示）で、主張は強い。
- モデルの注意: 語長 w = Θ(n+b) は標準の対数語長より長い。ただし論文は多語演算をビット演算の多項式回で実装し費用計上しており（implementation.tex:75–83）、語長の選択が指数に影響する箇所はない。

## 3. 構成と依存関係

```
入力 (a, t)
 ├─ n < n_* または b > 2^{0.00001n} → 素朴 meet-in-the-middle 2^{n/2}（implementation.tex:312–331）
 └─ 孤立化 (MVV): c_i = C a_i + u_i, t_s = Ct + s, O(n²) 個の目標（setup.tex:22–61）
     ├─ 予備探索: 相異なる部分和の meet-in-the-middle、各列を 2^{0.489985n} で打ち切り（setup.tex:147–209）
     │    E d(V) > 0.01004n なら確率 1−O(1/n) で判定終了
     └─ CONTINUE のとき（解析上は E d(V) ≤ 0.01004n の場合が本番）
         ├─ Thm 4.1 alias 抽出: 乱択素数 P ≈ 2^{ηn}、各 t_s について「P を法として一致するが整数では不一致」な部分集合を全列挙（aliases.tex）
         ├─ Thm 3.1 チェックサム推定: V_ρ = Σ_{c(I)≡ρ} e_P(φ(I)) を絶対誤差 1/8 で推定（checksum.tex）
         └─ 判定: B̂_s = V̂ − Σ_{alias} e_P(φ(I))。|B̂_s| ≥ 1/2 なら YES（implementation.tex:32–48）
```

**0.49 の出どころ**
- チェックサム側: 必要条件は E_x[M(x)² 2^{λ(Δ−u(x))}] < 2^{η}（checksum.tex:488–495 を整理すると −τ−Δ+0.5169 < 0 ⟺ 0.5169 < η）。論文の密度 f, g で左辺 = 2^{0.51497}（自作計算）、論文の証明書では < 2^{0.5168}。余裕は指数で 0.00082。
- alias 側: 訪問対の期待数 2^{n + (2h(1/4) − 1 − γ)m − ηn} < 2^{τn}（aliases.tex:244–253）。これが η ≥ 1 − τ + 0.0076 を強いる。
- 二つを合わせると τ ≈ 0.48996 が限界。したがって **0.49 は「フィルタ密度の最適化で得た 0.5169」と「alias 側の 0.0076」の綱引き**で決まる。設計上の自由度は f, g の係数（三角多項式 6 項ずつ）、κ、λ = 8.5 / 8.3、m、γ。

**重要な構造的事実（自分で導いた）**
- 2^{u(x)} ≤ Q_*(x) := ∫ f_*(x+w) g_*(w) dw（Jensen）、∫ Q_* = 1。よって E_x 2^{u} ≤ 1（自作計算: 0.99974）。u の大きい周波数（ū ≥ Δ）は Markov で 2^{(η−Δ)n} = 2^{τn} 個以下。これらは直接和、残りは重点サンプリングという分担になっている。単純な |J| 比例の重点サンプリングでは分散 (4/π)^{2n} = 2^{0.697n} が必要で足りない。直接和部分を切り出すことが本質。
- u, v を自由に選べる理想値は 2^{λΔ}(E (M²)^{1/(λ+1)})^{λ+1} = 1.3687（λ=8.5）。論文の構成は 1.4290。理想との差は小さく、この経路での τ の大幅改善は見込めない。

**「最悪ケース」に平均ケースの議論が紛れ込んでいないかの点検**
- 入力の分布は一切使っていない。乱数化は (i) 乱択素数 P, P'（整数差の衝突を Lemma 2.4 で抑える）、(ii) 位相 φ（固定 k で x_i(k) を一様化）、(iii) ブロック M・反転 F・表のラベル。
- 二乗平均誤差（checksum.tex:427–432）は G 上で点ごとに押さえてから元の φ 法で期待値を取っており、G で条件付けた φ を独立扱いしていない。正しい。
- 列長は期待値 + Markov + 打ち切りで、失敗は NO 出力に落ちる。時間上界は常に成立。
- alias の被覆は固定入力の「低欠損」性だけを使う（aliases.tex:320–325）。欠損が高い入力は予備探索が決める。この二分法は E d(V) の値で完全に分かれており、抜けはない。

## 8. 総括（約 150 語）

- 主張は「最悪ケース Subset Sum を 2^{0.49n} 時間、毎回の時間上界、正答確率 2/3」。既知の下界・仮説と矛盾しないが、長年の未解決問題を解く強い主張である。
- 構成は、MVV 孤立化、欠損度による二分法、alias の全列挙（表現法＋除外規則）、Fourier 和の重点サンプリング（直接和とサンプリングの分担）の 4 部。いずれも初等的で、深い定理には依存しない。
- 要の数値不等式（Prop. filtering-moments）を定義から独立に再計算し、1.42897, 1.42885 < 1.43078 で成立を確認した。指数の帳尻は 39/39、小型実装の恒等式・除外規則・不偏性・最終判定もすべて通った。確定した誤りは見つからなかった。
- 懸念は、必要な n が天文学的である点、数値余裕が指数で 0.0008 と薄い点、有限円スコアの計算手続きの記述が粗い点。
- 確信度: 検算した範囲で証明が正しい確率は**中〜やや高（6 割程度）**。残りは、専門家による被覆・条件付けの再検証と区間演算の機械検証で詰める必要がある。
