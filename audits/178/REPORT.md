## 1. 主張の正確な内容（限定条件を含む）

**定理 1.1（introduction.tex:24–34）**
- 入力: 整数 d ≥ 3 を固定し、偶数 n ≥ n_0(d)。
- 出力: n 頂点の単純 d 正則グラフ G の隣接リスト。
- 結論: A_G を 1^⊥ に制限した固有値 λ がすべて **開区間** −2√(d−1) < λ < 2√(d−1) に入る。特に G は連結かつ非二部。
- 計算量: O_d(n^{k_d}) ビット演算。k_d と n_0(d) は d にのみ依存するが、**どちらも明示されない**（introduction.tex:36–39 が明記）。
- 限定: n は偶数のみ（d が偶数で n が奇数の場合は扱わない）。n と d の同時多項式性や局所隣接クエリは主張しない。

**系 1.2（introduction.tex:41–49）**: 任意の大きい N について N ≤ |V(G)| ≤ N+1 の Ramanujan グラフ。定理 1.1 を N 以上の最小の偶数に適用するだけで、自明。

**定理 8.3（repair.tex:282–336、本論文の急所の定理）**: 単純 d 正則 G が (i) スペクトル閉じ込め x_i^σ := s − σλ_i > −e/20（e = n^{−2/3+a}, a = 10^{−4}, s = 2√(d−1)）、(ii) 局所スペクトル質量 Σ_{x_i^σ ≤ w}|v_i(p)|² ≤ C_0 w^{3/2}（2e ≤ w ≤ 2d、全頂点 p、両符号）、(iii) 典型辺ブロック（bulk 逆行列 R_B^σ の辺端点 2×2 ブロックが木ブロック (1/(d−2))[[√q, σ],[σ, √q]] に n^{−.024} 以内。例外辺は C_0 n^{−.1} 割合以下）を満たせば、M = ⌈n^{1/3+10a}⌉ 個の頂点非交差 switch で全非定数固有値を開区間 (−s, s) に入れる決定的多項式時間アルゴリズムがある。

## 2. 位置づけと、依頼文で確認を求められた点

- **出発点は Cohen 2016 の二部 Ramanujan グラフではない。** Cohen は関連研究として introduction.tex:83–84 で引用されるだけで、構成には使われない。本論文はスタブ（半辺）の決定的ペアリングによる **ゼロからの構成**（configuration model の脱乱択化）で、ペアリングの全期間にわたり両符号 σ = ±1 の精度行列 M(h) = z(h)I − σA_e − h𝒟 の正定値性を保つ（foundations.tex:36–45）。したがって「二部性を壊した後」という段階は存在しない。完成直後のグラフはすでに両側で ‖A|_{1^⊥}‖ < s + e/20（boundary.tex:1491–1497, algorithm.tex:134–138）。
- **「≤ か < か」**: 最終出力の正しさは、算法が出力候補ごとに行う **厳密有理数の慣性判定** B^T(4qI − A_G²)B ≻ 0（algorithm.tex:99–115、repair.tex:754–769）だけで担保される。この判定は 1^⊥ 上の二次形式の正定値性 ⟺ 全非定数固有値の平方が 4q 未満 ⟺ 開区間、で正確。**よって 6,000 行の解析に穴があっても、誤ったグラフが出力されることはなく、起こりうる失敗は「通る候補が見つからず出力なし」である。** 解析が保証するのは「通る候補が候補族に存在する」ことだけ（算法節: algorithm.tex:114–115, 149–152）。
- **「すべての偶数 n か」**: すべての偶数 n ≥ n_0(d) を主張し、証明もサイズ調整を必要としない（スタブは最初から n 頂点 × d 本で、ペアリングは頂点集合を変えない。repair も頂点集合不変: repair.tex:327–330）。特定の列の n だけ、という限定はない。
- 既知結果との関係（introduction.tex:51–129）: LPS/Margulis/Morgenstern（限定次数・算術列）、MSS2015/HPS2018（二部）、MSS2018+Cohen2016（二部多重グラフ、偶数位数すべて）、MOP2020/Alon2021（2√(d−1)+ε、全次数全サイズ）、HMY2024（ランダム正則グラフの Ramanujan 確率 → 約 0.69、存在のみ）。本論文は「全次数・全大偶数位数・厳密閾値・非二部・決定的」をすべて同時に主張する。これは HMY2024 の辺普遍性と同程度に強い「辺スケール局所法則」を **決定的に** 達成する主張を含み、既知のどの手法よりも強い。

## 4. 急所: 開区間を保証する不等式の鎖（定理 8.3 の証明を追った結果）

修復は switch（{u,v},{x,y} を削除し {u,y},{x,v} を挿入）M 個の同時適用。U = [e_u − e_x, e_v − e_y] として A_{G'} = A_G − UFU^T、したがって sI − σA_{G'} = (sI − σA_G) + U C_σ U^T（repair.tex:357–365。自作検算で一致）。

1. **bulk の消去（Step 1, repair.tex:369–415）**: 固定した bulk 切断 w_B^σ ∈ [W_b, 2W_b] で固有空間を近傍 E_0^σ（slack < w_B）と bulk に分け、S_B = C_σ^{−1} + U^T R_B^σ U を定義。理想ブロック σF + 2P_tree^σ = (1/(d−2))[[s, σd],[σd, s]] は行列式 −1、逆行列 K_σ = (d/(d−2))[[−s/d, σ],[σ, −s/d]]（**検算一致**）。S_B が理想ブロック対角に十分近ければ慣性が C_σ^{−1} と一致し、Haynsworth の慣性加法性から更新後 bulk 精度 D_B + U_B C U_B^T ≻ 0。近傍 Schur 補行列は正確に diag(x_i^σ) + U_E S_B^{−1} U_E^T（repair.tex:409–413 の式、**小グラフで恒等式として検算一致**）。
2. **平均の正のずらし（Step 2, repair.tex:417–516）**: 一様な辺対では E H_ii = −4x_i/((d−2)n)、すなわち slack を因子 1 − 4M/((d−2)n) で縮めるだけで負の slack を正にできない（**公式を検算で確認**）。そこで閾値に最も近い T_τ = {x_i^τ < t_T^τ}, t_T ∈ [2e, 3e] のモードに対し、辺対の法 ν₀ を密度 1 + (1/B_*)[−(2n/J_T) Σ_τ Σ_{i∈T_τ} z_i(g)^T K_τ z_i(j)] で傾ける。密度の正値性は局所質量 (ii) と Cauchy–Schwarz で括弧 = O(n^{−a/10})。傾斜後の平均は repair.tex:482–491 の式: 対角のみで、T_σ 上に +4/(B_* J_T n)·Tr(K_σ M_i K_σ M_i) > 0 が加わる（**この式（repair.tex:482–491）を総当りで恒等式として検算、誤差 10^{−16}**。Tr(KMKM) > 0 も |λ| < d で確認）。正バイアスの大きさ M/(J_T n) = n^{−2/3+8.4a} ≫ e が −e/20 の slack を上回る。これが repair.tex:512–516 の式: diag(x) + M E_ν H ⪰ ceI（c > 0）。
3. **ゆらぎ（Step 4, repair.tex:542–639）**: 対独立な M 回の抽選で、Frobenius 二次モーメントにより (a) 近傍和のゆらぎ √M W_b^{3/2} = n^{−5/6+155a} ≪ e、(b) ‖U_E U_E^T‖ ≤ CM/n、(c) ‖S_B − 理想‖ ≤ M/(√n W_b^{1/4}) = n^{−15a} ≪ en/M = n^{−9a}（条件 t_* > 8b_* − 4a）。衝突・既存辺の確率 M²/n = n^{−1/3+20a} = o(1)。**表 repair.tex:626–631 の 6 つの比の冪はすべて自作計算と一致。**
4. **結論（Step 5, repair.tex:640–660）**: 近傍 Schur 補行列 = diag(x) + ΣH_r + U_E(S_B^{−1} − 𝒦)U_E^T で、第 3 項は (CM/n)·o(en/M) = o(e)、ゆらぎと法の差し替えが各 o(e)。repair.tex:512–516 の ceI がこれらを上回り正定値。bulk も正定値なので sI − σA_{G'} ≻ 0 on 1^⊥（両符号）⟺ **厳密に** −s < λ < s。
5. **決定化（Step 6–7, repair.tex:662–769）**: 固有射影と R_B は Bernstein 多項式の有理近似、辺対の法は素数 P ∈ [n^{C'}, 2n^{C'}] の F_P 上で丸め、対独立性は γr + β の affine 構成。P² 個のシードを全列挙し、各候補を厳密慣性で判定。

**判定**: 定理 8.3 は仮定 (i)(ii)(iii) のもとで、私が追えた範囲（代数・慣性・期待値・指数算術・確率評価の構造）に誤りがない。「開区間」の余裕は repair.tex:512–516 の c·e から 3 つの o(e) を引いた残りで、最終判定は厳密慣性。

仮定の供給元: (i) は Prop 7.1 の正定値性（closest primary で z(h_*) − s < e/20, setup.tex:85–86）。(ii) は Lem 8.1: 全 primary での対角成分比較（誤差 B_B = o(√e)）と、同じ凍結参照の h 微分の有界性から、差分商で [R(s+w_p)²]_pp ≤ C/√w（repair.tex:65–97。不等式 1/(x+w_p)² ≤ [(x+w_−)^{−1} − (x+w_p)^{−1}]/(w_p − w_−) と z(h) − s = (1−√q h)²/h ⇒ |h−h_−| = O(√w) を確認）。(iii) は Lem 8.2: 分離停止時点の経路評価（長さ r_n = .08 log_q n 未満の非自明な戻りが n^{.08+o(1)} 頂点にしかない）と凍結補正の行ノルム平均（Σ_p‖p_{p,0}‖² ≤ l_0 ‖P̂_0‖²）から、例外割合 ≤ n^{−.2}（自作計算 n^{−.303} polylog）。

## 8. 必要な専門家

- ランダム正則グラフの局所法則（Bauerschmidt–Huang–Yau、Huang–McKenzie–Yau 系）: §5–7 の一段評価が、ランダム設定での既知の困難（辺での局所法則）をどこで回避しているか、見落とした障害がないかの判定。特に configuration pencil M(h) = zI − σA_e − h𝒟 による正規化と、スタブ露出マルチンゲールに沿った成分評価。
- 脱乱択化（pessimistic estimator、Raghavan、Wigderson–Xiao 系）: Lem 3.1 の多勘定同時割引と、割引損失 n^{C_*/3} を p 次モーメントから抜き出す構造の健全性。
- スペクトルグラフ理論・Ramanujan グラフ（Marcus–Spielman–Srivastava、Mohanty–O'Donnell–Paredes、Alon）: 定理 8.3 の switch による厳密修復のアイデアが既知手法と整合するか、仮定 (ii)(iii) が妥当か。

## 9. 総括と確信度

- 主張は「任意の固定 d ≥ 3、十分大きい全偶数 n で、非二部・単純・d 正則の **厳密** Ramanujan グラフ（開区間）を決定的多項式時間で構成」。出発点は Cohen 2016 ではなく、スタブの決定的ペアリングによるゼロからの構成で、途中段階に二部グラフはない。
- 証明の骨格は (1) 条件付き期待値法で両符号の精度行列を正定値に保ちながらペアリング、(2) 辺スケール n^{−2/3+a} での成分比較（局所法則）を貪欲選択に沿って維持、(3) 最後に傾斜した辺対分布による M = n^{1/3+10a} 個の switch で slack −e/20 を正に反転、(4) 出力は厳密有理数の慣性判定。
- 急所である定理 8.3 は、代数（K_σ、det = −1、Tr(KM) = −2x/(d−2)、傾斜平均の式 repair.tex:482–491、Schur/慣性恒等式）を記号計算と小グラフ総当りで検算し、全指数算術 22 件を厳密有理数で確認した。**仮定 (i)(ii)(iii) のもとで定理 8.3 は正しいと判断する（確信度 高、8 割以上）。** 開区間は repair.tex:512–516 の正定値余裕 c·e と最終の厳密慣性判定で担保される。
- 一方、仮定を供給する §5–7（約 3,800 行）は、スケールの整合性と構造的妥当性は確認できたが、一段推移評価の場合分けを独立に再導出できていない。ここは「決定的に辺スケール局所法則を達成する」という、ランダム設定での既知結果（HMY2024）と同等以上に強い主張の本体であり、誤りがあれば最も起こりやすい場所である。確定した誤りは見つからなかったが、未検証の分量が大きい。
- 懸念は、n_0(d) が 10^{600000} 以上と推定される点（実行不能、ただし誤りではない）、定数選択の順序が定性的な点、余裕が指数 10^{−4} 〜 10^{−7} と薄い点。
- 確信度: 検算した範囲（定理 8.3、補題 4.1、4.4、7.2 の骨格、全指数算術）に誤りはない。**証明全体が正しい確率は 中の下（3 割程度）**。残りは §5–7 の一段評価をランダム行列・脱乱択化の専門家が再検証することで詰める必要がある。出力の正しさ自体は慣性判定で無条件に保証されるので、誤りがあった場合の帰結は「出力なしで停止しうる」であって「非 Ramanujan グラフを出力する」ではない。
