## §1 定理の正確な主張

**Theorem 1.2**（`01-introduction.tex:38–45`）: F を μ12 を含む円分体とする。F の任意の有限位数 Hecke 指標 η（idele 類群の連続な有限像の指標、`01-introduction.tex:33–36`）について、L_F(s,η) の有理型接続は Re s > 1 − 10^{-6} に零点を持たない。

- 主指標は含まれ、s = 1 の極は許される（`01-introduction.tex:47`）。
- 幅 10^{-6} は体・導手・虚部によらない。ただし**定数と「十分大きい Z」の閾値は F, S, η に依存してよい**と明記されている（`01-introduction.tex:48–53`、`06-zero-free.tex:758–763`）。証明が実際に与える幅は 1/20000（`06-zero-free.tex:716–717`）。
- 定理は (F, η) ごとの定性的な主張（零点が無い）なので、定数の一様性は主張に含まれない。一様なのは**指数だけ**である。この点は §2.6 で確認した。
- 帰結: F = Q(μ12)、η = 1 とすると ζ_F(s) = ζ(s)·(Dirichlet L 関数 3 つ) なので、ζ(s) が Re s > 1 − 10^{-6} に零点を持たないことが出る。**これは未解決の準リーマン予想そのもの**である。

## §2 証明の機構の再構成

### 2.1 一枚の絵

F, η, 有限集合 S（複素素点、6 の上の素点、η の導手、小さい素点などを含み、S 整数環 R が単項イデアル整域になるように取る。`02-arithmetic.tex:17–33`）を固定する。大きな Z に対して 1 つのスカラー I_Z = I(Z^a, Z^b, Z) を作り、2 通りに評価する（a = 9/10、b = 133/1000。`02a-coefficient-family.tex:69–76`）。

- **(上界)** I_Z ≪ Z^{933/2000+ε}（Prop 7.2、`05-poisson.tex:194–246`）。
- **(主項)** I_Z = c_0 f_η(Z) + O(Z^{7/15−0.0004})、c_0 ≠ 0（`06-zero-free.tex:676–681`）。ここで
  f_η(Z) = (1/2πi)∫_{(2)} Z^{ξ−8/15} e^{(ξ−5/6)^2} H_η(ξ)/L^S(ξ,η) dξ（`06-zero-free.tex:461–469`）。

933/2000 = 7/15 − 1/6000 なので、f_η(Z) ≪ Z^{7/15−1/20000} が出る。f_η の Mellin 変換は Re s > 1 − 1/20000 で正則になり、それが e^{(s−5/6)^2}H_η(s)/L^S(s,η) と一致する。H_η は零点を持たないので、L^S(s,η) はそこに零点を持てない（`06-zero-free.tex:709–752`）。

**不等式の向きと正値性**: 最後の段は Landau 型の解析接続の議論で、**正値性は使っていない**（3-4-1 型の不等式も、係数の非負性も出てこない）。零点 ρ があれば f_η(Z) に Z^{ρ−8/15} の大きさの項が出るはずだが、それが上界と両立しない、という構造である。私はこの最終段（`06-zero-free.tex:691–752`）を手で追い、Fourier 反転による Re s = 2 上での一致と一致の定理による延長に不備が無いことを確認した。

### 2.2 行の和 B_m(Z) と theta 関数

中心の対象は、m ∈ R に対する

B_m(Z) = Σ_{c 平方因子なし, n} γ_2(c)/(q_c^{1/2} q_n) · ϑ(A) χ_A(m) P_G(q_A/Z)、A = c n^3

である（`02a-coefficient-family.tex:41–49`）。γ_2(c) は 3 次指標 χ_c^2 の正規化 Gauss 和、χ_A(m) は **6 次**剰余指標、ϑ = \bar Λ \bar G η は Hecke 指標、P_G は対数 Gauss 関数。

- **theta との関係**: γ_2(c)/(q_c^{1/2}q_n) は、PGL_2 の 3 重被覆上の例外表現 Θ（Kazhdan–Patterson の 3 次 theta 表現）の球 Whittaker 関数の値の積である（Cor 5.2、`03-theta.tex:186–205`）。局所的には W(a(ϖ^e)) が e = 3k で q^{-k}、e = 3k+1 で q^{-k−1/2}·g_2、e = 3k+2 で 0（`03-theta.tex:147–157`）。これは Patterson の 3 次 theta 関数の Fourier 係数（平方因子なしの添字で 3 次 Gauss 和）を adele の言葉で書いたものにあたる。
- **角度型**: ϑ は各複素素点で角度指数 ±1 を持つ（Λ が Q(ω) の Grössencharacter の相対ノルムとの合成だから。`02-arithmetic.tex:423–424`、`606–625`）。そのため球ベクトルではなく、その 1 階 Lie 微分のベクトルを使う（`03-theta.tex:292–305`）。theta 関数の定数項は複素トーラスについて動径的なので、角度指標と積分すると消える（`04-reflection.tex:197–210`）。**これが「極（主項）が出ない」理由**である。
- **6 次の捩り**: χ_A(m) は、m を割る各素点で上三角冪単元 n(v/p) を右から掛けて指標 α_{p,j}(v) で足し合わせることで挿入する（`04-reflection.tex:67–97`、`109–132`）。

結果として B_m(Z) は theta 関数の S 上のトーラス積分の、核 K(T) による平均として正確に書ける（Lemma 6.1、`04-reflection.tex:222–241`）。

### 2.3 反射（Lemma 6.2、6.3）と 2 次 large sieve

有理 Weyl 元 w による保型性 θ(wg) = θ(g) を使う（`04-reflection.tex:133`）。m をちょうど 1 回割る素点 p では、局所計算

w n(v/p) = n(p/v) a(−p^2/v^2) \bar n(p/v)

と被覆のトーラス余輪体 C_p(ϖ,u) = χ_p(u)^{-2} から、反射後の係数は ω_p χ_p(t)^1（|ω_p| = 1、周波数は ν = t/p^2 の形）になる（`04-reflection.tex:356–366`）。一方、反射後の列の素点 q（平方因子なしの c′ を割る）の球 Whittaker 値は χ_q(·)^2 を単数因子に持ち、周波数の分母 d^{-2} から χ_q(p)^{-4} が出る。相互法則で

χ_p(q)^1 · χ_q(p)^{-4} = χ_p(q)^{-3} = χ_p(q)^3（**2 次指標**）

となる（`04-reflection.tex:764–775`）。**6 次の捩りが、被覆の 3 次の余輪体と合わさって 2 次の捩りに変わる。これが証明の機構の核心**である。

- 反射後の和の長さは q_m^2/Z（`04-reflection.tex:915–931`）。行は q_m ≍ Z^{M_0}、M_0 = a + b = 1.033 なので、長さは Z^{2M_0−1}。
- 2 次指標については Heath-Brown 型の最適な large sieve（C + D）(CD)^ε が使える（Lemma 6.4、`04-reflection.tex:941–956`）。3 次・6 次の一般の large sieve には (CD)^{2/3} の項があり、これでは足りない。
- 結果: Σ_m |B_m(Z)|^2 ≪ Z^{2M_0−1+ε}（Prop 4.1、`02a-coefficient-family.tex:101–121`、証明は `04-reflection.tex:1027–1228`）。

私の独立な確認:
- 古典的な言葉での再導出（**私の手計算。スクリプトには無い。Γ(3) 型の群と primary な元での概略で、3 の上の補正と上半空間の座標の細部は省いている**）:
  - f(γw) = κ(γ)f(w)、κ(γ) = (c/d)_3^σ（σ = ±1）、Fourier 係数 τ(μ) とする。Σ_{v mod p} χ_p(v)^{-j} f(w + v/p) は係数を τ(μ)χ_p(μ)^j·G(χ^{-j}) に変える（Gauss 和の変数変換）。
  - 尖点 v/p を ∞ に送る γ_v（左下が p、右下 d ≡ v^{-1} mod p）で f(w + v/p) = κ(γ_v) f(−d/p − 1/(p^2 w))。3 次の相互法則で κ(γ_v) = (d/p)_3^σ = χ_p(v)^{-2σ}。
  - よって和は Σ_v χ_p(v)^{-j−2σ} Σ_μ τ(μ) e(−μ v^{-1}/p)(…) = Σ_μ τ(μ) χ_p(μ)^{-(j+2σ)} G(χ^{j+2σ})(…)。**捩り χ^j は反射で χ^{-(j+2σ)} に移る。**
  - σ = 1 のとき j ↦ −(j+2) は対合で、1 ↔ 3（6 次 ↔ 2 次）、0 ↔ 4、2 と 5 は不動。論文の b_{j,0} ≡ 8 − j（周波数を p^2 倍して測り直すと同じもの）と整合する。対合であることはスクリプト D 部の最後で確認した。
  - **この再導出が与えるのは写像 j ↦ −(j+2σ) だけ**である。どちらの向き σ にどちらの Gauss 和（χ^2 か χ^4）が対応するかは、この計算からは出ない。それは次項の付録 A の殻の計算に依り、その計算は論文が書いた余輪体の規約を入力にしている。
- 余輪体の向き C(ϖ,u) = χ(u)^{-2} と、Whittaker 値に出る Gauss 和が χ^2 のもの（g_2）であることの整合は、付録 A の Jacquet 積分を自分で殻ごとに計算し直して確認した（§4 C 部）。**この向きは主項の符号に直結する**（g_2 でなく g_4 なら γ_1γ_4 は Hecke 指標にならず、1/L は出ない）ので、重点的に見た。
- 捩り j = 4 の行（m が 4 乗を含む）では反射後の長さが短くなるという論文の主張（`04-reflection.tex:376`）は、「3 次 Gauss 和の Dirichlet 級数 Σ g(k,c)λ(c)N(c)^{-s} は、Hecke 指標 λ の 3 乗が自明でない限り極を持たない」という私の理解と整合する（**推論**。この命題の出典を私は特定しておらず、確認もしていない）。

### 2.4 Poisson 側と主項

I(X,Y,Z) は、B_m(Z) を加法的な多項式 q_s^{-1/2} g_s(−m)（q_s ≍ Y）と組み合わせた平均である（`05-poisson.tex:92–102`）。

- **上界**: 加法的 large sieve（Lemma 7.1）で加法因子の ℓ^2 質量は ≪ Y^{-1}。Cauchy–Schwarz と Prop 4.1 で I ≪ (Z^{2M_0−1}/Y)^{1/2} = Z^{933/2000}。
- **主項**: m について Poisson 和公式を使う。完全和は 6 次 Gauss 和 √q·γ_1(c)·\bar χ_c(h) を出し、恒等式 γ_1(p)γ_2(p) = −Λ(p)G(p)（`02-arithmetic.tex:415–422`）と ϑ = \bar Λ \bar G η から、素点ごとに **−η(p) q_p^{-ξ}** が出る（`05-poisson.tex:607–627`）。したがって c についての和は Σ μ(c)η(c)q_c^{-ξ} 型、つまり **1/L^S(ξ,η)** になる。s と A の相互作用は相互法則で打ち消し合う（`05-poisson.tex:515–535`）。
- 双対周波数 h は h = u r^6（u は 6 乗を法とする代表）と分解される（`02-arithmetic.tex:305–317`）。u = 1（6 乗の周波数）だけが、ζ^S(w) の w = 1 と ζ^S(6z) の z = 1/6 の両方の極を持つ。二重留数が c_0 f_η(Z) で、指数は a/2 + ξ − 1 + h_0/6 = ξ − 8/15。
- u ≠ 1 の行は 1/L^S(ξ, η\bar χ_•(u)) を含む。ここは Re ξ = 1 + 10^{-7} での自明な評価、L^S(w, χ_•(u)) の convexity 評価（Re w = 0.003）、および零点密度（Prop 8.2）で抑える（`06-zero-free.tex:479–645`）。

**指数の構造（私の整理）**: 反射側の余裕は 7/15 − 933/2000 = (4 − 4a − 3b)/6 で、4a + 3b < 4 が必要。一方、非主要行の「良い行」の評価は、ξ を 0.998 に動かさない場合、主要項の指数を +0.00074 上回る（スクリプト E 部）。つまり 2 つの要請は同じ 1 次式を逆向きに縛り、**論文の評価の組み立て（convexity、行の個数 ≪ U、この積分路）の中では、零点密度による 0.002 の利得が無ければ両立しない**。(a, b) = (0.9, 0.133) は許される狭い領域の中にある。目安として、1/1000 刻みの格子 44,850 点（0.85 ≤ a < 1、0 < b < 0.3）のうち、**この 2 つの余裕だけ**を、論文の積分路の定数（Re w = 0.003、Re z = 0.4、Re ξ = 0.998、行の閾値 Z^{h_0+10^{-5}}）を固定したまま満たすのは 170 点だった。他の制約（R_w、R_z、小さい行、遠い行）は調べておらず、積分路を取り直した場合の領域も調べていない。

### 2.6 一様性

「すべての導手・すべての虚部で幅が同じ」になる理由は、単純に次のとおりである。

- 定理は (F, η) ごとの主張で、F, S, η は最初に固定される。**幅を決めるのは Z の指数だけ**で、定数と閾値は F, S, η に依存してよい。最後の Mellin 変換の収束半平面は、f_η(Z) ≪_{F,S,η} Z^{7/15−1/20000} の**指数**だけで決まる（`06-zero-free.tex:758–763`）。
- 指数が体によらない理由を tex で追った。すべての large sieve と個数評価がイデアルノルムで書かれている: 加法的 large sieve は N + V^2（`05-poisson.tex:129–134`。δ^{-d_F} ≪ N + V^2 で次数 d_F が消える、`161–189`）、導手 large sieve は N + U^2（`06-zero-free.tex:43–51`）、2 次 large sieve は C + D、convexity は導手ノルムの 1/2 乗（`06-zero-free.tex:144–148`）、イデアルと 𝒰 の個数は ≪_F ノルム。
- 体に依存する指数が 1 つだけある。convexity の高さの指数 A_F（`06-zero-free.tex:141–152`）で、これは ρ < 1/(A_F+1) の選び方に吸収され（`260–264`）、Z の指数には入らない。虚部の裾は Gauss 因子 e^{(ξ+z−1)^2} と M(z) の減衰で U^{-ρA_1} として処理される（`583–601`）。私はこの処理を読んで、筋が通ることを確認した。
- 虚部 t についての一様性は、η を η|·|^{it} に取り替えるのではなく、Mellin 変換が**半平面全体**で正則になることから一度に出る。

**ここに誤りは見つからなかった。** 「定数は依存してよいが指数は依存しない」という区別は、読んだ範囲では一貫して守られている。

### 2.7 既知の障害との整合

この種の議論から準リーマン予想が出ないと考えられてきた理由と、本論文の該当箇所を並べる。以下は私の**推論**であり、文献で確認したものではない。

1. **一般の係数では成り立たない不等式を使っていないか。** 003 の形で言えば、Σ_{N(u)≤H}|Σ_n a_n χ_n(u)|^2 ≪ D^{1+ε}H（H ≈ D）は一般の a_n（例えば a_n = 1）では偽である（6 乗の u が H^{1/6} 個あり、そこで和が D になる）。本論文はこれを一般の係数には主張していない。係数が theta 係数（Gauss 和）であることを保型性を通じて使う。
2. **3 次 large sieve の最適性（Dunn–Radziwiłł）との関係。** 3 次指標で捩った 3 次 Gauss 和の和は極（X^{5/6}）を持ち、3 次 large sieve の (MN)^{2/3} 項は落とせないとされる。本論文は (i) 捩りを 6 次にして反射後に 2 次にする、(ii) 角度指標 \bar Λ で定数項（極）を消す、の 2 点でこれを避けている。(ii) については Q(ω) での数値実験で、角度の捩りを入れると X^{1/3} の主項が消えることを観察した（§4 の `theta_sum_check.py`。観察したのは主項の消失までで、急減少までは確認できていない）。
3. **Euler 積を持たない関数への適用可能性。** 関数等式だけを使う議論は、Davenport–Heilbronn 型の関数（Re s > 1/2 に零点を持つ）にも通ってしまうので、成立し得ない。本論文は主項の同定（γ_1γ_2ϑ = −η から 1/L が出る）で η の乗法性を本質的に使っているので、この反例には当たらない。
4. **Siegel 零点とパリティ。** 篩と large sieve だけでは例外零点を排除できないとされる。本論文で篩でない入力は、(i) 恒等式 γ_1γ_2 = −ΛG（μ と 6 次 Gauss 和の積が 3 次 Gauss 和と Hecke 指標の積になる、Hasse・Heath-Brown の関係）と (ii) theta の保型性である。**この 2 つで障害を越えられるという主張が、既知の障害と矛盾するとは私には示せなかった。逆に、越えられることを独立に確認もしていない。**
5. **関数体での整合。** 同じ議論が関数体で通るなら結論は真（RH は既知）で、矛盾は生じない。

「この議論が偽の結論を導く変種」を作って破綻させる試みも行った（符号を変えて主項を L(ξ,η) にする、小さい行だけを使う、など）。符号は Hecke 指標では変えられず（素点すべてで −1 を取る指標は無い）、小さい行（q_m^2 ≪ Z）では両辺が自明に小さくなるだけで、矛盾は作れなかった。

- **§5 の「gap」4 件は、論文の欠落ではなく「当初の監査で未確認だった依存」と呼ぶ。** Codex は Kazhdan–Patterson の原典（Publ. IHES 59、印刷頁 44、51、61、72、79、110、114、122）と訂正文（Publ. IHES 62）を照合した。
  - 指摘 1（Prop 5.1 の KP 依存）: Cor I.3.6、Thm II.2.5(a)(b)、§II.1 の記述は論文の引用と一致。重要な依存であることは変わらないが、「論文の重大な欠落」とする根拠は無い。規約を含む特殊化の全体を再証明したわけではない（Codex 自身の留保）。
  - 指摘 3（有理 Weyl 元の持ち上げ）: **ほぼ解消。** KP §0.2（印刷頁 51）が、Borel と Weyl 元の有理的な持ち上げを局所切断の積で定義している。重大度は「中」から下げる。
  - 指摘 4（unfolding・Fubini）: 監査役が再証明していないことは、論文の gap の証拠ではない。論文は絶対優級数を実際に提示している。
  - 指摘 5（3 の上の素点）: KP Prop I.2.1 と Thm I.2.9(e) には tame の条件が無く、wild な素点にも適用できる形。この理由による gap は認めにくい。
- **§0 の 3 と §2.4、指摘 17: 「同じ 1 次式 4a+3b を逆向きに縛る」は不正確。** 良い行の条件は 4a + 2.991b > 3.994033 で、同一の 1 次式ではない。「ξ の移動が無いと反射側の条件と両立しない」という結論は保たれる。数値（1/6000、−377/300000、0.000857、+0.000743）は Codex の再計算と一致。0.00086 は小さい損失を入れる**前**の余裕。
- **§0 の 4 と §2.5: 「目標の L 関数には Euler 積だけを使う」は字義どおりには不正確。** 最後に通常の有理型接続も使う（06-zero-free.tex:746–749）。正確には「捩りの族の大部分について非消滅を論文内で証明して使い、目標の指標には仮定しない」。
- **§2.7: Dunn–Radziwiłł の 3 次 large sieve の最適性（下界）は GRH 条件付き**で、偏りの主項は X^{5/6}/log X。「既知の障害を回避した」ではなく「既知の最適性の結果から直ちには反証されない」と書く。
- **§2.6: 一様性は零点なし帯の幅についてだけ。** 体を動かす応用の節までは検証していない。
- **checked OK 8〜16 は強さが揃っていない。** 8・9 は最終段の解析と数値計算、10〜13 は局所の式を前提にした代数と有限例の照合（`local_checks.py` は殻の表現やトーラスの規則を入力としている）、14〜16 は論証を読んだ結果。109 件の成功は、局所の式が大域的に適用できることまでは検証しない。
- **§7 の「10〜30%」は公開文面から外す。** 主観であって、監査から導かれた確率ではない。公開では確認した範囲と未確認事項を示す。
