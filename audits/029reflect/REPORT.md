## 1. 課題 0: 何を検証できるのか

1. **029 の Lemma 6.3 そのものは、どの体でも数値化できない（停止規則に該当）。** 右辺の輪郭 Φ_{υ,κ} は「Weyl 元で回した S ベクトルの Whittaker 関数 f_{w,υ}」から作られ（`04-reflection.tex:509–534`）、そのベクトルは cutoff の補題（`03-theta.tex:398–446`）で存在が示されるだけで、2・3 の上の素点での模型も U も S も明示されていない（`02-arithmetic.tex:17–33`）。以後の実験を「Lemma 6.3 を検証した」とは呼ばない。
2. **Q(ω) は 029 の仮定を満たさない。** μ12 が tex で使われるのは (i) χ_p(−1) = 1（`02-arithmetic.tex:406–408`）、(ii) Hilbert 記号の対角が自明（`:197–198`、allowed generator の前提）、(iii) 局所 Weyl 計算で a(−1) の記号が自明（`04-reflection.tex:390–392`）。Q(ω) では N(p) ≡ 7 (mod 12) の素元で χ_p(−1) = −1。最小の体は Q(ζ12)。
3. **Q(ζ12) では実行しない。** 2・3 の上を含む theta の全 Fourier 係数（Patterson の定理 8.1 にあたるもの）、他の尖点の展開、乗数系の明示式が手元に無く、代用品になるため。
4. **Q(ω) で検証できるのは 003 の Proposition `lem:reflection` と、029 Lemma 6.2 の指数の対応。** 辞書: 029 の行の指数 8−j（`04-reflection.tex:371–375`）と列の −4（`:764–775`）の合成 4−j は、003 の B_{p,j} = χ_p^{−j−2}（`paper2.tex:1735–1742`）と 6 を法として一致。j = 1 で 2 次、j = 4 で付値 e > 0 の項、j = 0 で N^{-1/2}χ^{-2}。単位係数は 029 の ω_p =（2 次 Gauss 和）/τ_{p,1} = χ_p(−1)γ_1γ_3 と 003 の ω_{p,1} が対応。交差項は 029 の ρ の χ_p((d/p)^{-2}) と 003 の κ(g_1) の (a/r)_3 が対応。
5. **「合格」の意味**: (P1) DR が転記した Patterson の係数と Kubota 指標で θ が保型的、(P2) χ_p^j で捩った theta 級数が χ_p^{−j−2} で捩った級数の尺度 p の反転に等しい（単位係数・交差項込み）、(P3) 3 の上の ray class の捩り（003 の φ）込みでも総当たりの保型性の層で成立。
6. 検査は Mellin 変換の前の、H³ 上の点ごとの恒等式で行う。合格基準は相対誤差 10^{-8} 以下（計算の前に決めた）。

## 2. 課題 A: 反射公式の両辺の等式（Q(ω) の類似物）

**結論: 合格。** 成立すべき恒等式の最大相対誤差は 2.5×10^{-13}（事前の基準 10^{-8}）、負の対照はすべて O(1) で不一致。

### 道具立てと正規化
- θ(w) = σ v^{2/3} + Σ_{μ∈λ^{-3}O} τ(μ) v K_{1/3}(4π|μ|v) ě(μz)、σ = 3^{5/2}/2、ě(z) = exp(2πi(z+z̄))、λ = √−3。
- τ は DR (5.7)、他の尖点は DR (5.13)(5.14) と Appendix A の d_10、d_19。Kubota 指標は Γ_1(3) 上で (c/a)_3、SL_2(Z) 上で 1。
- 3 次 Gauss 和 g̃(π) は定義どおり総当たり。N(A) ≤ 200,000 の primary 元 72,208 個、素元 18,020 個。
- 6 次指標は χ_p(x) ≡ x^{(N−1)/6}、γ_j(p) = N^{-1/2} Σ χ_p^j(y) ě(y/(λp))（003 の定義）。

### 減少開始の予測（計算の前に核から出した）
- 対数 Gauss 重み（幅 w）の双対核 |H|(x) を数値積分で計算した。w = 0.1 では x = 10³ で 0.8、10⁴ で 0.012、10⁵ で 5×10^{-7}。w = 0.05 では 10³ で 2.5、10⁴ で 0.18、10⁵ で 3×10^{-4}。
