## 1. 主張の正確な内容

**Thm 1.1（01-introduction.tex l.19–27）**
- 有限連結 3 次元 CW 複体 X で、
  - H_i(X̃; Z) = 0（i > 2）、
  - H^3(X; M) = 0（すべての Z[π_1 X] 加群 M、局所係数）
  を満たし、しかも 2 次元以下の有限 CW 複体とホモトピー同値でないものが存在する。
- π_1(X) = G は無限群。「有限」は胞体構造の有限性（l.29–30）。

**D(2) 条件の定義との照合**
- l.7–11 の定義は Wall 1965 §2 / Johnson 2003 の標準形（H_i(X̃)=0 (i>2) かつ H^3(X;M)=0）。l.9 は「有限生成 M」と書くが、定理（l.23）と Prop 3.1(ii)（03-plus.tex l.24–25）はすべての左 ZG 加群で示しており、定理の方が強い。整合している。
- 「有限 D(2) 問題」= 有限 D(2) 複体は有限 2 複体とホモトピー同値か、という Wall 1979 Problem D3 の形。Johnson の本の定式化（有限表示群 G ごとの D(2) 性質）とは「G について反例」の意味で一致する。

**基本群 G の明示的表示（04-construction.tex l.14–27）**
- P = ⟨x_1, a_1, x_2, a_2, s | x_1 a_1 x_1⁻¹ = a_1⁴, x_2 a_2 x_2⁻¹ = a_2³, x_1 = a_2¹³, s x_2 s⁻¹ = a_1⁵⟩
- t_1 = x_1², t_2 = x_2³、K = ⟨⟨t_1, t_2⟩⟩_P、G = P/K。
- 監査役による整理: G は有限群のグラフの基本群（virtually free）。頂点群 A = ⟨x_1,a_1⟩ ≅ Z/15 ⋊ Z/2（位数 30）、B = ⟨x_2,a_2⟩ ≅ Z/26 ⋊ Z/3（位数 78）。辺群は Z/2（x_1 = a_2¹³ の融合）と Z/3（s による x_2 ↦ a_1⁵ の HNN）。グラフは 2 頂点 2 辺の閉路。
- G_ab = Z ⊕ Z/6、H_2(G; Z) = 0、有理 Euler 標数 χ(G) = 1/30 + 1/78 − 1/2 − 1/3 = −307/390（`check_group.py`）。

**障害（Thm 2.3 / Cor 2.4、02-tower.tex l.103–109, l.230–236）**
- Cor 2.4: Y を有限連結 2 次元 CW 複体、ρ: π_1(Y) → C^× を指標とする。H_2(Y; C_ρ) = 0 なら、ρ は有限位数元をすべて 1 に送る。
- 本例では ρ(x_1) = −1、x_1 は G で位数 2、H_2(X; L_ρ) = 0。したがって X ≃ Y（有限 2 複体）は不可能。

**本論文が正しい場合の波及（論文は明言していない）**
1. **Relation Gap 問題の肯定的解決。** 導出は次のとおり。
   - Lemma 4.1（K_ab = 0）は、5 生成元表示 F_5 → G の関係加群 N_ab が r_1,…,r_4 の像で生成されることと同値（N/[N,N]N_P = K_ab）。よって d_G(N_ab) ≤ 4。ZG 上のこの主張自体は Lemma 4.1 の手計算で確認した。`check_fox.py` が確かめたのは Q[G_ab]（4 成分）と Q[A], Q[B] 上の像での所属という必要条件のみ。
   - Prop 3.1(iii) と rank D = 4、χ(B) = 0、h_0 = 0 から h_1(G; C_ρ) = 0。
   - π_1 = G の任意の有限 2 複体 Y で h_2(Y;C_ρ) = χ(Y) + h_1(G;C_ρ) = χ(Y)。Cor 2.4 で h_2 ≥ 1、ゆえに χ(Y) ≥ 1、def(G) ≤ 0。
   - したがって d_F(N) ≥ 5 > 4 ≥ d_G(N_ab)。これは relation gap そのもの。
   - 補足: 論文の l.47（t_1 = a_2²⁶ = [t_2,a_2]）により t_1 ∈ ⟨⟨t_2⟩⟩_P。実際 r_2 から x_2³a_2x_2⁻³ = a_2²⁷、t_2 = 1 で a_2²⁶ = 1、r_3 で x_1² = a_2²⁶ = 1。よって G = ⟨5 生成元 | r_1..r_4, t_2⟩ は 5 関係子表示を持ち def(G) ≥ 0。本論文の結果と合わせると def(G) = 0 ちょうど。この 5 関係子表示について d_F(N) = 5、d_G(N_ab) ≤ 4 となる。
2. **G は inefficient**（def(G) = 0 < b_1 − d(H_2) = 1）。virtually free な inefficient 群は、監査役の知る限り新しい。
3. **一般的な deficiency 上界**: Cor 2.4 は Euler 標数を介して「G に有限位数元 g と ρ(g) ≠ 1 なる指標があれば def(G) ≤ h_1(G; C_ρ)」と同値。古典的な上界 def ≤ 1 + h_1(G;C_ρ) を 1 だけ改良する。
- これらは 50 年来の未解決問題を 2 頁の初等的議論で解決することを意味する。波及は大きいが、監査役は既知の結果との矛盾を見つけられなかった。

## 6. 監査できていない部分

- Thm 2.3 を計算機で反証する試み（def = 1 かつ捩れを指標で検出できる群の探索）は、GAP なしでは実行できなかった。既知の群での検査は等号成立例ばかりで、反例の探索としては弱い。
- G の deficiency が本当に 0 であることの独立な確認（Thm 2.3 を使わない方法）。これが得られれば本論文の正しさはほぼ確定する。
- Mannan 2009 Thm 3.4、Hambleton 2019 Lemma 2.1 / Thm B、Wall 1979 Problem D3 の番号は原典で未確認。
- Hofmann–Nicholson Theorem A の内容。
- Prop 3.1 の「Hurewicz で α_j を S² で表す」段（03-plus.tex l.54–57）は標準的と判断し、詳細は追っていない。

## 7. 必要な専門家

- (a) 低次元トポロジー・2 複体の専門家（Howie 型の塔の議論に通じた人）: Thm 2.3（02-tower.tex l.103–225）の全段。特に l.157–171（Euler 標数から b_1 ≥ 1）と l.207–222（単体数の厳密増加）。
- (b) 群の deficiency / relation gap の専門家（Harlander、Bridson–Tweedale の系統）: §2 の言い換え「def(G) ≤ h_1(G;C_ρ)」が既知の例（deficiency 1 で捩れを指標で検出できる群）で破れないか。破れる例が一つあれば Thm 2.3 は誤り。
- (c) D(2) 問題の専門家（Mannan、Nicholson）: Prop 3.1 と Mannan 2009 の対応、および本例が Johnson–Mannan の代数的 2 複体（ZG⁴ → ZG⁵ → ZG、自由加群）の実現不可能例になっている点の整合性。

## 8. 総括

本論文は、virtually free な無限群 G（有限群のグラフ、辺群 Z/2 と Z/3）に対して、有限 plus 構成で χ = 0 の有限 D(2) 3 複体 X を作り、指標 ρ(x_1) = −1 と塔の議論（Thm 2.3）で 2 次元模型の非存在を示す。計算部分（Fox 行列、小行列式、K の完全性、G の構造、H_2(G) = 0、安定化との整合）はすべて自作コードで再現でき、誤りはなかった。Thm 2.3 の証明も 2 回読んで穴を見つけられなかった。ただし Thm 2.3 は同時に Relation Gap 問題を肯定的に解き、G が inefficient であることを含意する。論文はこれを述べていない。確信度: 計算部分と Prop 3.1・Lemma 4.1 は高い。Thm 2.3 と主定理全体は中程度で、専門家の検証を要する。
