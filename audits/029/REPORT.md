## 1. 主定理

**Theorem 1.1**: a ≠ −1 で、a が平方数でないとき（admissible）、c_a > 0 と x_a があって、x ≥ x_a なら次が成り立つ。
- #{p : x < p < 2x, ord_p(a) = p−1} ≥ c_a·x/(log x)²
- 無限性と、x/(log x)² の尺度の下界だけを主張している。予想されている正の密度（x/log x の尺度）と Artin 定数は主張していない。

**Theorem 1.2（中核）**: μ12 を含むすべての円分体 F と、F 上のすべての有限位数 Hecke 指標について、L_F(s,η) は Re s > 1−10⁻⁶ に零点を持たない（証明の中で実際に得られている幅は 1/20000）。
- F = Q(μ12) とすると、ζ(s) の準リーマン予想が出る。F = Q(μ12q) とすれば、すべての Dirichlet L 関数について同じことが言え、Landau–Siegel 零点も排除される。
- **それ自体が Artin 予想よりはるかに大きい主張である。**

## 2. 構成

- **§2（Hooley の論法の制限版）**
  - p − 1 = c·r·Q（Q > x^0.9 は素数、r は中間サイズの素因数だけを持つ）の形の素数を ≫ x/L² 個作る。
  - (a/p) = −1 にすることで index を奇数にする。
  - Hooley が GRH を必要とした中間範囲 x^δ < q < √x が、最初から出てこない。その代わり、得られる個数は x/L² に減る。
- **§3〜8、付録 A**: 定理 1.2 の証明。
  - 3 次 metaplectic theta 表現（Kazhdan–Patterson）の Fourier 係数を、6 次指標で捩った和を作る。
  - 二乗平均の上界（Heath-Brown、Goldmakher–Louvel の large sieve）と、Poisson 展開の主項 1/L^S(s,η) を比べる。
  - 7/15 − 933/2000 = 1/6000 の余裕から、零点のない領域を得る。

## 3. GRH はどう回避されているか

**回避してはいない。** GRH の代わりに、無条件で一様な零点のない半平面（定理 1.2）を、論文の中で自前で証明したと主張している。Kummer 体に対する Bombieri–Vinogradov や零点密度評価は使っていない。定理 1.2 を認めれば、次数と導手についての一様性は正しく処理されている（log D_q + n_q ≪ q² log q、q ≤ exp(L^0.3) なので x^{−δ0} が吸収する）。
