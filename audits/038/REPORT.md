## 0. 結論

**明確な誤りは見つからなかった。** 主な流れ（Prop 3.2 → Lemma 4.2/Prop 4.4 → Lemma 4.5 → Prop 5.1 → Lemma 6.1/6.2 → KV 消滅による持ち上げ）は、行単位で検算した範囲では内部的に整合している。

従来の手法（Angehrn–Siu / Kawamata 型の lc center の切り下げ、subadjunction、Nadel 消滅）は使っていない。指数型の汎関数を最小化し、その一次変分を使う新しい手法である。

## 1. 主定理（Thm 1.1）

- **主張**: C 上の滑らかな連結射影多様体 X（すべての次元 n）と ample な L について、K_X + (n+1)L は大域生成される。
- **系 6.3**: m ≥ n+1 のすべてについて成り立つ（X × P^r に適用する。この計算は検算済み）。
- very ampleness の部分は主張していない。klt 対も扱っていない。

## 2. 証明の地図

1. **§3**: x で生成されないなら、平均消滅位数の liminf が n/(n+1) を超える。等号の場合（V = 1）は、Howald の単項式版、Demailly–Kollár の半連続性、blowup 上の KV 消滅で処理する。
2. **§4**: 汎関数 F_{m,t}(v,s) を、基底と単項式テストについて最小化する。一様な評価、旗多様体上の lct 閉集合、コンパクト性によって最小値が達成される。
3. **§5（核心）**: 正次元の中心 W をもつ最小化元は存在しない。
   - 上界: 一次変分から T_m ≤ d/t。
   - 下界: 制限像の一様下界（Lemma 5.2。L^d·W ≥ 1 の整数性だけを使う）、離散 Brunn–Minkowski、単体による最小化から liminf T_m ≥ d·I_*。
   - t を n+1 に十分近く取れば I_* > 1/t となり、上界と矛盾する。
4. **§6**: 一点中心の最小化元からスケール変分と支持不等式を導き、有理化と摂動で境界因子 B を作る。KV 消滅で持ち上げ、Lemma 2.5 で X に降ろす。
