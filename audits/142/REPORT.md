## 1. 主張の正確な内容

**Thm 1.1（00-introduction.tex:27–38）**
- 入力: 2 進表現の素数 p と、F_p[x] の非零な密表現多項式 f（次数 n）。
- 出力: 先頭係数 c と、相異なるモニック既約因子 g_i とその重複度 e_i（f = c∏g_i^{e_i}）。定数なら空リスト。
- 計算量: O(((n+1)⌈log₂p⌉)^{10^12}) ビット演算、絶対定数つき。
- 使わないもの: 乱数、整数因数分解オラクル、原始根オラクル、GRH（00-introduction.tex:36–37）。
- ただし要旨と 00-introduction.tex:21–25 が明記するとおり、証明はコンパニオン論文 [OpenAIPrimitive26, Theorem 1.2]（= 成果 029）の零点なし定理を使う。本文では Thm 11.1（10-analytic.tex:9–18）として引用のみで、証明はない（10-analytic.tex:6–7「Its proof is not part of this paper」）。

**Thm 1.2（条件付き帰着、00-introduction.tex:61–71）**
- B = 20 + (n+1)(L+1)、L = ⌈log₂p⌉（(1.1)、00-introduction.tex:47–49）。
- p > B^{200000} かつ n ≥ 2 のとき、各素数 q ≤ n について補助素数 ℓ_q が入力に追加される。条件 (1.2)（00-introduction.tex:52–55）は原文どおり
  ```
  ℓ ∉ {2,3,p,q},   ℓ ≡ 1 (mod 12q),   p^{(ℓ-1)/q} ≢ 1 (mod ℓ)
  ```
  すなわち p が ℓ を法として q 乗剰余でない（00-introduction.tex:56）。
- E = max(2, max_q ℓ_q) として O((B+E)^C) ビット演算。**E への依存はビット長ではなく数値そのもの**（00-introduction.tex:73–74）。したがって ℓ_q が B の固定冪で抑えられるときだけ多項式時間になる（75–77）。
- Thm 1.2 自体はコンパニオンの定理を使わない（79–80）。

**Thm 11.1（コンパニオン Thm 1.2 の引用、10-analytic.tex:9–18）**: μ₁₂ を含むすべての円分体 K と、K のすべての有限位数 Hecke 指標 χ について、L_K(s,χ) は Re s > 1 − 10⁻⁶ に零点を持たない。導手・虚部に制限なし。K = Q(μ₁₂)・自明指標とすると ζ_{Q(μ₁₂)}（ζ(s) を因子に含む）の零点なし帯、すなわちリーマンゼータの準リーマン予想を含む。

**GRH 条件付きの系（10-analytic.tex:172–176、00-introduction.tex:102–104）**: 有限位数 Hecke L 関数の GRH は上の帯を含むので、Thm 1.2 だけから「GRH の下で決定的多項式時間因数分解」が出る、と述べている。

## 4. 急所の検証

### 4.1 補助素数 ℓ_q の条件と GRH の壁

**結論を一文で**: ℓ_q の大きさを GRH なしで多項式的に抑える古典定理は存在せず、論文も使っていない。唯一の入力はコンパニオンの Thm 11.1 である。

- 条件 (1.2) は「ℓ ≡ 1 (mod 12q)」だけではなく「p^{(ℓ−1)/q} ≢ 1 (mod ℓ)」を含む（00-introduction.tex:53–54）。前者だけなら Linnik の定理で ℓ ≪ q^{O(1)} が無条件に取れるが、後者は p の ℓ を法とする q 乗非剰余性、すなわち Kummer 拡大 M = K(p^{1/q})、K = Q(μ₁₂q) における Chebotarev 型の条件である（10-analytic.tex:101–111 の設定どおり）。M/Q は非アーベルなので Dirichlet L 関数だけでは足りず、K 上の位数 q の Hecke 指標が要る。
- q = 2 に特化すると意味が明確になる。ℓ ≡ 1 (mod 24) は ℓ ≡ 1 (mod 4) を含むので平方剰余の相互法則から (p/ℓ) = (ℓ/p)。よって ℓ₂ は「p を法とする素数の平方非剰余で ≡ 1 (mod 24) のもの」の最小値である。`check_142_table.py` の T3 で、p < 3000 の全素数について、(1.2) の直接判定による最小 ℓ₂ と「素数 ℓ ≡ 1 (24), (ℓ/p) = −1」の最小値が一致することを確認した（最小素数非剰余 n_p との比は最大 204.5、例 p = 1217 で ℓ₂ = 457、n_p = 3）。
- したがって Prop 11.3（10-analytic.tex:91–98、q = 2）は「p を法とする最小の素数平方非剰余は ≪ (log p)^{2·10^7}」という **GRH なしの Ankeny 型評価**を主張している。無条件に知られている最良の評価は Burgess の p^{1/(4√e)+o(1)} であり、polylog 評価は GRH（Ankeny: (log p)²）の下でしか知られていない。これはコンパニオンの中身を読まなくても分かる、Thm 1.1 の事前確率を低く見る最も明快な根拠である。
- Prop 11.3 の証明（10-analytic.tex:100–158）は、Thm 11.1 を認めれば標準的な「平滑化された明示公式による効果的 Chebotarev」であり、手で追って整合を確認した:
  - [M:K] = q（X^q − p が p 上で Eisenstein、p ∤ 12q は p > B^{200000} から）、ζ_M = K 上の q 個の Hecke L 関数の積（105–111）。
  - 判別式評価 log D_K ≤ [K:Q]log(12q)、log D_M ≤ q log D_K + [K:Q](q log q + (q−1)log p)、合わせて ≪ B³（113–122）。計算: [K:Q] ≤ 12q ≤ 12B、log p ≤ L ≤ B。
  - x = T·B^{2·10^7} で相対誤差 x^{−δ}B³ = T^{−δ}B^{−20+3} = T^{−δ}B^{−17}（128–130）。δ·2·10^7 = 20 で整合。
  - 誤差項: j ≥ 2 の冪と剰余次数 ≥ 2 の素イデアルは O([K:Q]√x log² x)、2,3,p,q 上の素イデアルは O([K:Q] log x)（133–145）。いずれも x に対し o(1)。
  - 残る 1 次の素イデアルは ℓ ≡ 1 (mod 12q) 上にあり、p^{(ℓ−1)/q} ≡ 1 なら M/K で完全分解して q^{−1}Ψ_M の q 項と正確に相殺、惰性する場合はノルム ℓ^q で負の項として捨てられる（147–157）。補助素数が (x, 2x) に無ければ差が c₁x 未満になり矛盾。c₀ = 2T。
- Lemma 11.2（10-analytic.tex:39–87）は「引用・標準」であり、独立には再導出していない。等高線移動の一様性、s = 0 の零点の位数 ≤ d_M、Hasanalizade–Shen–Wong 2022 の零点計数の引用（72–76）は妥当に見える。

**依存関係の整理**: 142 が必要とするのは「μ₁₂ を含む円分体 K = Q(μ₁₂q) 上の位数 q の Hecke 指標すべて」に対する一様な幅の帯である。監査 029 の報告によれば、029 の Thm 1.2 は証明の核心（3 次 metaplectic theta 係数の反射展開）が検証できておらず、信頼度は低い。029 の報告が触れる成果 003（Q(√−3) 上の Hecke と Dirichlet に対する幅 7/8、Lean 化済みとされる）は、仮にそのまま認めても 142 の必要とする体と指標の族を覆わない。029 の Thm 1.2 は未形式化。142 にも Lean はない。よって **142 の無条件主張の信頼度は 029 の Thm 1.2 の信頼度を上限とする。**

### 4.3 p ≤ B^{200000} の分岐

- 定義: 08-driver.tex:93–94。処理: Step 5 で非スカラー b ∈ B_h を取り gcd(h, b − a) を a = 0..p−1 で全列挙（08-driver.tex:128–130）。正当性は 08-driver.tex:170–172（b の座標のいずれかを a に取れば非自明）。
- コスト: 1 呼び出しあたり ≤ B^{200000} 回のスカラー試行、その他 O(B^{1000})、全体 O(B^{201000})（09-complexity.tex:281–285）。p ≤ B^{200000} なので poly(B) に収まる。この分岐では表も曲線も使わない（281）。
- 大きい分岐で使う閾値の不等式: (N+4g+1)² < B⁶ < p と 2Nq(q−1)(N−2) < B⁶ < p（07-odd-split.tex:183, 199–201）、p > r³（Lemma 9.1）、p > N（Prop 2.3）、p > h² で h ≤ B⁴（Lemma 2.2、09-complexity.tex:111–118）、格子 B^{400} < p（09-complexity.tex:235–241）。いずれも B^{200000} 未満で整合。
- 実用上の注意（誤りではない）: B ≥ 20 + 3(L+1) なので p > B^{200000} は L が数百万ビット以上の素数にしか成立しない。現実に走らせうる入力では、本アルゴリズムは O(p) ループつきの Berlekamp そのものである。純粋に漸近的・理論的な結果。

## 8. 総括と確信度

- 主張は「F_p[x] の完全因数分解を (n+1)log p の多項式時間で、乱数・オラクル・GRH なしに行う一様な決定的アルゴリズム」。構成は、補助素数から表を作り、偶数次は向き付け、奇数次は巡回被覆 Y^q = F(X) の Jacobian で λ = 1−σ による持ち上げとラベル検査で分離する。
- 無条件性の全体重はコンパニオン 029 の Thm 1.2（準リーマン予想を含む一様零点なし帯）に掛かる。補助素数の条件 (1.2) は Linnik 型ではなく Kummer 拡大の Chebotarev 条件で、q = 2 では「小さい素数平方非剰余」そのもの。Prop 11.3 の導出は Thm 11.1 を認めれば正しい。
- 代数的帰着 Thm 1.2 は全節を精読して誤りを見つけられず、核心の Lemma 4.3 / Cor 4.5 は種数 1 の総当たり実例で鋭く確認できた（深さ ≤ m−1 で有理、深さ m で消滅、基礎体では深さ 1 で消滅）。16 項目の補題検算は全て通った。
