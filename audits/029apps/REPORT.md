## 1. 問い

第 7 波（`audits/029core/REPORT.md`、README 11-11 追記）で残した点:

> 029 の定理 1.2 の証明では、定数と閾値が体 F と指標 η に依存してよい（一様なのは最終段の指数だけ）。
> 一方、応用の節では体が動く（029 では K_q = Q(μ_q, a^{1/q})、142 では Q(μ_{12q}) と M = K(p^{1/q})）。
> 応用側が、導手や判別式についての明示的な依存を定理 1.2 から別に必要としていないか。

## 2. 結論

**読んだ範囲では、必要としていない。応用の節に誤りは見つからなかった。**

理由は構造的なもの。定理 1.2 の**文面**は「μ12 を含むすべての円分体 F と、すべての有限位数 Hecke 指標 η について、Re s > 1 − 10^{-6} に零点がない」で、定数も閾値も高さの制限も含まない（029 `01-introduction.tex:38–45`、142 `10-analytic.tex:9–18`）。零点が「ない」という主張は体ごとに真か偽かであって、証明の途中の定数が体に依存しても、結論には残らない。

応用の節が体について量的に使うのは次の 3 つで、どれも定理 1.2 とは独立の入力である（3 つ目は Codex の指摘で追記。当初は「2 つだけ」と書いていた）。

1. 次数と判別式の上界（初等的。円分体の判別式公式と、べき基底の判別式）。
2. Dedekind ゼータの零点の個数の一様な評価（Hasanalizade–Shen–Wong 2022。定数は絶対）。
3. 左の線 Re s = −1/2 上の一様な評価 |ζ_K′/ζ_K| ≪ log D_K + n_K log(2+|t|)（関数等式と、Re s = 3/2 で絶対収束する Euler 級数から）。

したがって「定理 1.2 が文面どおり正しい」ことだけを仮定すれば、応用の節の一様性は従う。**負担はすべて定理 1.2 そのもの（各体・各指標での零点なし）に乗っており、応用の節が負担を増やしてはいない。** これは定理 1.2 が正しいことの確認ではない（そこは `audits/029core/` と `audits/029reflect/` の対象）。

## 6. 気づいた点（誤りの指摘ではない）

1. **「十分大きい x」が始まる位置は天文学的に遠い。**【Codex の指摘で訂正】当初ここに「閾値は L = log x > 4.3×10^8 程度から」と書いたが、これは誤った結び付けだった。4.3×10^8 は、誤差の上界の**第 2 項だけ**について、定数を無視した比較 −δ_0 L + L^{0.3} + 2 log L = 0 の交点（`check_apps.out`）であって、証明全体の閾値ではない。その L では第 1 項と x/L² の比 L·exp(−L^{0.1}) がまだ約 2.9×10^5 あり、この比が 1 を下回るのは L ≈ 3.4×10^{15} から（主担当が計算し直して確認）。さらに隠れた定数があるので、どちらも明示的な閾値ではない。言えるのは「tex は絶対定数・十分大きい x としか言っておらず、それは正しい。実用的な範囲については何も言わない」まで。142 の T も T^{−δ} で絶対定数を打ち消すので、T は（定数）^{10^6} の規模になりうる。
2. **029 が定理 1.2 を実際に使うのは F_q = Q(μ_{12q})、q が大きい素数、η が位数 q の Kummer 指標（と主指標）の場合だけ。** 142 は Q(μ_{12q})、q ≤ n の素数、位数 q の指標。どちらも「すべての有限位数 Hecke 指標」という全体は使っていない（観察。定理 1.2 の証明がこの特殊な族で簡単になるかどうかは未検討）。
3. 142 の q = 2 では、補助素数 ℓ ≡ 1 (mod 24) は p の平方非剰余になる（相互法則。§4 で確認）。Prop 11.3 が正しければ最小の平方非剰余 ≪ (log p)^{2·10^7}。これは第 6 波の記録どおり。
