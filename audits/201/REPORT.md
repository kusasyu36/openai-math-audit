## 1. 主定理（Theorem 1.1）

標数 0 の可算な斜体 D で、中心 F = Z(D) について次を満たすものが存在する。
- ある x, y について D = F[x,y]（単位的多元環として 2 元で生成される）。
- [D : F] = ∞。
- D のすべての元が F 上で代数的。ただし次数に一様な上界はない。

副産物として、可算な中心部分体 k∞ と R = k∞[x,y] についても同じ主張が成り立つとしている。中心 F は具体的には指定されていない。

**既知結果との整合**: 矛盾は見つからなかった。
- Golod–Shafarevich からは nil 多元環しか得られない。
- Jacobson / Kaplansky、Bell–Drensky–Sharifi は次数が一様に有界という仮定を使う。
- Amitsur の定理は非可算体についての主張。
- 引用 [6] Goodearl–Letzter（arXiv:2604.18480）の実在は未確認。
