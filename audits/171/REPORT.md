## 0. 主定理

ある絶対定数 C > 0 があって、すべての n ≥ 0 で R(Q_n) ≤ C·2^n が成り立つ（Burr–Erdős の立方体予想）。

- 証明は背理法による存在証明で、C の値は出てこない。
- 補題 2.1 で、単色の Q_n を含まない 2 部グラフの 2 色付けの列（C_n = N/2^n → ∞、N ≤ n2^n）を取り、それが存在しないことを示す。
