(a) コンパクト台の重み（stage5_bump.py、stage5_a_compact.py、stage5_a2_tight.py）
----------------------------------------------------------------------
重み: W(y) = b(log y / a)、b(u) = exp(−(1−u²)^{−p})（|u|<1）、p = 4、a = 3。台は [e^{-3}, e^{3}]、C_c^∞ なので
命題の仮定（:670、:1293）の中。依頼の例 p=1 は最初の計画表で上界が使いものにならず（|C| あたり 5e-2 以上）、
同じ族の p>1 に広げた（比較を走らせる前、上界だけを見て）。X = 49737（X·e³ ≤ 10^6 となる最大。直接和は有限和で
打ち切りなし）。B・P=∅ だけ X = 20000 も。
比べたもの: T(X;Ψ)（eq:T :1287）と Σ_群 C·Σ_ℓ d·α/√N·ψ·ΠB·V^♯（:1806、C は :3420、V^♯ は :1752 の文面どおり）。
基準（実行前にスクリプト冒頭に書いた）: |差| ≤ Btot。Btot = 双対和の尾の上界 (T3′) + V^♯ の求積の上界 (Q′)
  + 丸めの目安。Btot ≤ 1e-2·|T| のときだけ「意味のある比較」と呼ぶ。主張するのは「Btot 以内の一致」で、
  観測した差の小ささではない。
上界の作り方（段 4 と同じ流儀で導き直した）: 重みの Mellin 変換の絶対値を、u の積分路を複素側にずらして出した包絡で
  抑える（Cauchy の定理。任意の η で成り立つ）。それを Re t = A に移した積分 Mt(A) と、格子点数・係数の上界
  27N^{1/6} を掛ける。厳密でないのは、包絡と Mt(A) の 1 次元の数値積分、丸めの目安。
  包絡が実際の |V̂| を上から抑えていることは、A=0（実軸上）でだけ数値で確かめた（比の最大 1.000）。A≠0 は Cauchy の議論に頼っている。

できない理由（数値）: 両側の級数が表に収まるには N(c)·(1+|z/v|²) ≤（両側の限界の積）が要る。T=40 では限界が
  1/v ≤ 60.5 なので積は 3660、N(c) = 3276 だと |z/v|² ≤ 0.12 で、a/c の真上から動けない。T=22 でも |z/v| ≤ 1.64。

「小さい分母の尖点の近くで θ が指数的に小さい」という私の説明は、7 個のうち 2 個（v_q = 7.2）でしか数値と
  きれいに合わず、残りは説明しきれていない（推論にとどまる）。

4. 気づいた点（試した事実と推論）
======================================================================
1. 【試した】コンパクト台でも、表が届く範囲で直接和と双対和は相対 1e-9〜1e-13 で一致した（上界の保証はそれより

3. 【試した】依頼の例の隆起関数（p=1）では、尾の上界は最良の場合（B・∅）でも |C| あたり 5e-2 以上で、
   どの回も意味のある比較にならない見込みだった。p を上げると Mellin 変換の減衰が速くなり、p=4 が最良付近。
4. 【推論】上界と実測の 6〜7 桁の開きは、尾の和の相殺による。相殺を使う上界は作っていない。
