1. 方針（2026-11-19、作業開始時に記入）
======================================================================
- 段 5 の上界が粗かった主因は、係数の上界を各点の最悪値 27·N(ℓ)^{1/6}（締め直し版でも 18.72·N^{1/6}）で
  入れていたこと。実際の係数は |d(ℓ)| = 9|G(A)|、|G(A)| = N(b)^{1/2}（A = n b³、n は平方因子なし）で、
  N^{1/6} に届くのは A が立方数のときだけ。和の形で (n, b) の二重和として抑えれば、N(A) ≈ 10^6 付近で
  ほぼ N^{1/6} ≈ 10 倍の改善が見込める。数値積分は増やさない（係数の和は格子点の数え上げと閉じた式）。
- 表は伸ばさない（構築は Nmax の 2 乗で伸び、2e6 で 2 時間超）。まず上の上界でどこまで届くかを計画表で見る。
- 段 5 と同じ設定（p=4, a=3, X=49737）は観測差がもう見えているので、新しい上界を当てても「事後」。
  本判定には、結果をまだ見ていない設定（別の重み・別の X・別の素元）を入れる。段 5 と同じ設定は別枠。
- 上界の設計そのものが段 5 の結果を見た後であることは、スクリプトに明記する。

2. 上界の導出（式）
======================================================================
前提（ここでは証明しない）: 表の先の ℓ でも、係数 d_σ(ℓ) は kubota.build_series に実装された式（DR (5.7)、
(5.13)、(5.14)、付録 A。論文 paper2.tex :3104-3128 と :1858-1867）のとおりである。具体的には
  σ = ±: λ⁴ℓ = uA（u は σ ごとに決まった 3 つの単数、A は primary）のときだけ非零で、|d(ℓ)| = 9|G(A)|。
  σ = 0: ℓ = ±λ^{3k−3}A（k ≥ 0）で |d| = 3^{k/2+5/2}|G(A)|、ℓ = uλ^{3k−4}A（k ≥ 1、u は 6 単数）で |d| = 3^{k/2+2}|G(A)|。
  |G(A)| = N(b)^{1/2}（A = n b³、n は平方因子なし、n・b は primary）、ある素元の指数が 3 で割って 2 余れば G(A) = 0。
  （論文 :3123-3128 は |t_0| ≤ 3^{k/2+2}|b|、3^{k/2+5/2}|b|、m = −4 で |t_±| ≤ 9|b| と書いている。上の形はそれと整合。）
  A は primary なので λ と素。したがって (族, k, 単数, A) → ℓ は単射。

定義: D_σ(s, R) = Σ_{N(ℓ)>R} |d_σ(ℓ)| N(ℓ)^{−s}。
  (a) σ = ±: N(ℓ) = N(A)/81 なので D_±(s, R) = 3·9·81^s·P(s, 81R)。
  (b) σ = 0: D_0(s, R) = Σ_{k≥0} 2·3^{k/2+5/2}·3^{−(3k−3)s}·P(s, R/3^{3k−3}) + Σ_{k≥1} 6·3^{k/2+2}·3^{−(3k−4)s}·P(s, R/3^{3k−4})。
     k > 40 の分は P ≤ P(s, 1/2) と等比級数（公比 3^{1/2−3s} < 1）で抑える。
  (c) P(s, M) = Σ_{A primary, N(A)>M} |G(A)| N(A)^{−s} ≤ Σ_{b primary} N(b)^{1/2−3s}·Z(s, M/N(b)³)。
     （A ↦ (n, b) は単射。n の平方因子なしの条件を捨てるので上界。）
  (d) Z(s, M′) = Σ_{n primary, N(n)>M′} N(n)^{−s} ≤ Σ_{M′<N(n)≤T0} N(n)^{−s}（全部数え上げ、T0 = 2·10⁴）
       + S(s, max(M′, T0); d=3)。
     S は段 4 の (S) と同じ Abel 和の上界: 最小距離 d の格子（の平行移動）の点で |ℓ|² ≤ t のものは
     U(t) = π(√t + d/√3)²/(√3d²/2) 個以下（各点の Voronoi 六角形が半径 √t + d/√3 の円に入る）。
     f 減少なら Σ_{N>R} f(N) ≤ ∫_R^∞ U(t)(−f′(t))dt。f = t^{−s} で閉じた式
       S(s, R; d) = (π/cov)·s·[R^{1−s}/(s−1) + 2ρR^{1/2−s}/(s−1/2) + ρ²R^{−s}/s]、ρ = d/√3、cov = √3d²/2、s > 1。
     1+3O は 3O の平行移動なので d = 3。
  (e) b の和: N(b) ≤ B0 = 2·10⁴ は全部数え上げ、N(b) > B0 は Z ≤ Z(s, 1/2) と Σ_{N(b)>B0} N(b)^{1/2−3s} ≤ S(3s−1/2, B0; 3)。
群の尾（表の先 N(ℓ) > R）:
  |Σ_{N(ℓ)>R} C·d(ℓ)·α·ψ·ΠB·V♯(N(ℓ)X/N(c)²)| ≤ |C|·Bmax·min_A (cX/N(c)²)^{−A}·Mt(A)·D_σ(1/2+A, R)
  （|α·ψ| = 1、|ΠB| ≤ Bmax、|V♯(x)| ≤ (cx)^{−A}Mt(A)（段 5 の (V′)、A > 0）。c = (2π)⁴/27。）
厳密でない部分（導出ではなく評価の段階）:
  - Mt(A) と包絡 Env は数値積分（段 5 の stage5_bump.py）。段 12 では Mt を τ の格子上の片側 Riemann 和
    （Env は τ について非増加: 各 Gauss–Legendre 項がそうなので、計算値でも厳密に非増加。|Q(A+iτ)| が τ ≥ 0 で非減少であることは §2c で証明）
    で評価する（Mt_upper）。ただし格子の端より先の τ 積分と、包絡の中の 800 点 Gauss–Legendre 積分は上から抑えていない。
  - 浮動小数点の丸めは抑えていない（段 5 と同じ「目安」1e-13·Σ|項|）。
  - 表の中の V♯ の計算に使う V̂(−iτ) の u 方向の台形求積（NU = 8001）の誤差は抑えていない。
  - 求積の上界 Q′ は段 5 のまま（Mt(±0.8) を台形で評価）。
  - 包絡 ≥ |V̂| を数値で確かめたのは実軸上（A = 0）だけ。A ≠ 0 は Cauchy の定理による議論に頼る。
  - したがって以下の「保証桁数」は、REPORT §10 の言い方に従えば「上界の式を数値評価した誤差見積もりによる桁数」。

2c. |Q(A+iτ)| の単調性（最終確認の段階で追加。格子上の数値確認を証明で置き換える）
======================================================================
Q(t) = Γ(7/6+t)Γ(5/6+t)/(Γ(7/6−t)Γ(5/6−t))、t = A+iτ、A > 0、τ ≥ 0。|Γ(z̄)| = |Γ(z)| なので
  log|Q| = Σ_{x∈{7/6,5/6}} [log|Γ(x+A+iτ)| − log|Γ(x−A+iτ)|]。
Im ψ(y+iτ) = Σ_{k≥0} τ/((y+k)²+τ²)（ψ(z) = −γ + Σ_k (1/(k+1) − 1/(z+k)) から。極を通らない τ > 0 で成立）、
d/dτ log|Γ(y+iτ)| = −Im ψ(y+iτ) より
  d/dτ log|Q| = Σ_x Σ_k τ·[1/((x−A+k)²+τ²) − 1/((x+A+k)²+τ²)]。
(x+A+k)² − (x−A+k)² = 4A(x+k) > 0 なので各項 ≥ 0。よって |Q(A+iτ)| は τ ≥ 0 で非減少（すべての A > 0）。
Mt_upper が各区間で使う max(|Q(t_i)|, |Q(t_{i+1})|) は |Q(t_{i+1})| に等しく、区間上の上界になっている。

6. 対照のまとめ
======================================================================
- 生死はすべて、双対和を計算する前にコードで確かめた（切り替えがその材料を変える大きさを印字）。
- 3|c（Ψ0 = A）では NE2 が構造上 DEAD（全群で α(c) = ±1）。1 回目はこれを見落として必須に入れ、判定を不成立にした。
  2 回目は probe2 で群ごとの α(c) を印字して確かめたうえで、必須から外した。
- 新設の J は j=1 の本枠の全 10 回（1 回目 6、2 回目 4。別枠 K の 1 回を除く）で生きていて落ちた。ただし見たのは
  j=1 → j=5 の取り替え 1 種だけ。j=1 では B_{p,1} = χ^{−3} が 2 次指標（値 ±1）なので、指数の符号の誤り（χ^{+3}）は
  原理的に見えない。言えるのは「B_{p,1} を B_{p,5} に取り違える型の誤りは、この精度で見分けられる」まで。

言えること:
- 食い違いは 0 件。1 回目・2 回目・別枠の全 22 回（構造版の上界で意味のない 3 回を含む。スモークテストは K と同じなので数えない）で |T_dir − T_dual| は Btot12 の内側。
- コンパクト台の重み（命題の仮定の中）で、1 素元 j=1（(c,λ)=1、N(p) = 7 と 13）は、2 回目の事前登録の基準で
  「意味のある比較」が成立し（4 回、上界の桁 2.3〜3.7）、一致は Btot12 以内。3|c（Ψ0 = A、素元なし）も同様（2 回、3.8 桁）。
  論文に印刷された係数の主張だけを前提にした上界でも、j=1 は 3 回（2.0〜3.0 桁）、3|c は 2 回（2.9 桁）で成立。
  ただし W3 の B・{p13:1} は 2.01 桁で、基準（2 桁）との余裕は約 2%（境目ぎりぎり）。またこの上界の前提は監査対象の
  論文自身の補題で、独立に確かめた事実ではない。
- 1 回目の事前判定は「不成立」。原因は食い違いではなく、対照の規則の設計ミス（3|c で構造上効かない NE2 を必須にした）。
- 観測した相対差は j=1 で 1.5e-10〜2.4e-8（N(p)=13 は 1e-8 台、N(p)=7 は 1e-10〜1e-9 台）。これは上界ではない。
言えないこと:
- F・{p7:1}（v_λ(c)=1・j=1）と A・{p7:1}（3|c・j=1）は、どの重みでも上界が届かず、意味のある比較になっていない

  τ 格子の端より先の積分（上から抑えていない）、(3) 丸め（目安のみ）、(4) 表の中の V♯ の u 方向の台形求積（NU=8001）、

  誤差見積もりによる桁数」。
